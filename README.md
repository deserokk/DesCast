# DesCast

Flat screens placed anywhere inside a house. They sit in world space and are correctly
hidden by walls, furniture and people. Show an image from your PC or a link, or several on
a rotation, and share a whole room of them with your Free Company from one file.

## Install

Add this to Dalamud's custom plugin repositories, once:

```
https://raw.githubusercontent.com/deserokk/DalamudPlugins/main/pluginmaster.json
```

Then install **DesCast**. `/descast` opens it.

The window explains itself — every field has a tooltip, and anything that goes wrong says so
in place rather than failing quietly.
